# Sara Fawad - CS313 Web Engineering Lab 3

## Lab
HTML Advanced - Personal Portfolio II

## Project Description
This project is a multi-page personal portfolio created using HTML and external CSS.

## Pages
- index.html - Home/About Me
- hobbies.html - Hobbies and interests
- skills.html - Technical and soft skills
- gallery.html - Five-image hobby gallery
- contact.html - Contact information

## CSS Features
- External stylesheet
- Consistent fonts, colors, borders and spacing
- Horizontal navigation
- Float and clear properties
- Gallery images arranged using float
- Responsive-width layout

## Technologies
- HTML5
- CSS3

## Note
The images included in the project are self-contained illustrative SVG images related to the portfolio topics, so the website works without external image links.
